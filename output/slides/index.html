Ch.1 AI 發展脈絡
人工智慧的三次浪潮
Three Waves of Artificial Intelligence

發展時間軸

第一波浪潮（1950-1980s）
  • 符號 AI（Symbolic AI）：以邏輯規則與知識庫為核心
  • 代表：專家系統（Expert System）
  • 困境：脆弱、無法泛化，遭遇 AI 寒冬
第二波浪潮（1980-2010s）
  • 機器學習（Machine Learning）：從資料中學習統計規律
  • 代表：SVM、決策樹、貝氏網路
  • 成就：語音辨識、影像分類初步成功
第三波浪潮（2010s-今）
  • 深度學習（Deep Learning）：多層神經網路、大數據、GPU
  • 代表：CNN（影像）、RNN（序列）、Transformer（語言）
  • 成就：GPT、AlphaGo、DALL-E 等突破性成果

English Definition

Artificial Intelligence (AI) refers to the simulation of human intelligence by computer systems. Modern AI predominantly employs machine learning, wherein algorithms learn from data rather than relying on explicitly programmed rules. The current era is defined by deep learning — a subset of machine learning using multi-layered neural networks capable of learning hierarchical representations from large datasets.

Overfitting vs Underfitting

過擬合（Overfitting）
  • 訓練集表現好，測試集差
  • 模型過於複雜
  • 解法：正規化、Dropout、更多資料
欠擬合（Underfitting）
  • 訓練集與測試集均表現差
  • 模型過於簡單
  • 解法：增加模型複雜度
Bias-Variance Tradeoff：高偏差 = Underfitting；高變異數 = Overfitting。
來源：通識（機器學習分類）

模型評估指標
Model Evaluation Metrics

混淆矩陣（Confusion Matrix）

預測正（Positive）預測負（Negative）
實際正TP（真正例）FN（漏報）
實際負FP（誤報）TN（真負例）
Accuracy = (TP + TN) / (TP + TN + FP + FN)
Precision = TP / (TP + FP)  — 預測正確率
Recall = TP / (TP + FN)  — 找回率 / 靈敏度
F1-Score = 2 × Precision × Recall / (Precision + Recall)
重要：在資料不平衡（Class Imbalance）時，Accuracy 可能誤導評估。應使用 F1-Score 或 ROC-AUC。

交叉驗證（Cross-Validation）

K-Fold Cross Validation
  • 將資料分為 K 份（通常 K=5 或 10）
  • 輪流以一份為測試集，其餘為訓練集
  • K 次結果取平均作為最終評估
  • 優點：更穩健的泛化估計

常用損失函數

MSE（回歸）: $\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$
Cross-Entropy（分類）: $-\sum y_i \log(\hat{y}_i)$

英文術語

  • Generalization：泛化能力（在未見資料的表現）
  • Regularization：正規化（防止過擬合）
  • Hyperparameter：超參數（訓練前設定的參數）
來源：通識（模型評估）

K 近鄰演算法（KNN）
K-Nearest Neighbors (KNN)

核心概念

KNN 是一種非參數（Non-parametric）的監督式學習演算法。預測時，找出距離查詢點最近的 K 個訓練樣本，以多數決（分類）或平均值（回歸）決定結果。

直覺理解：「物以類聚」。一個樣本的類別，由其周圍最近的 K 個鄰居決定。

演算法步驟

  1. 計算查詢點與所有訓練點的距離
  2. 排序，取最近的 K 個點
  3. 分類：K 個鄰居中多數決；回歸：取平均
Euclidean Distance（歐氏距離）：
$d(x, y) = \sqrt{\sum_{i=1}^{n}(x_i - y_i)^2}$

英文技術定義

K-Nearest Neighbors (KNN) is a non-parametric, instance-based learning algorithm. It makes predictions by identifying the K training examples closest to a query point in feature space, using a distance metric such as Euclidean or Manhattan distance. For classification, the majority class among K neighbors is returned; for regression, the mean of K neighbors' values is used. KNN has no explicit training phase — computation occurs entirely at inference time, making it a "lazy learner."

優點與缺點

優點缺點
概念簡單、無訓練階段 推論時間 O(nd)，較慢
不假設資料分布 高維度時效果差
（維度詛咒 Curse of Dimensionality）
適合小型資料集 需儲存所有訓練資料
自然支持多分類 K 值選擇影響結果
K 值選擇：K 太小 → 過擬合；K 太大 → 欠擬合。通常以交叉驗證選取最佳 K。

支援向量機（SVM）
Support Vector Machine (SVM)

核心原理：最大化邊界

SVM 尋找能最大化類別間邊界（Margin）的超平面（Hyperplane）。支援向量（Support Vectors）是距離超平面最近的訓練樣本，決定超平面的位置。

線性可分 SVM 目標：
最大化邊界 $\frac{2}{||w||}$，等價於最小化 $\frac{1}{2}||w||^2$
限制條件：$y_i(w \cdot x_i + b) \geq 1$

Kernel Trick（核技巧）

當資料線性不可分時，使用核函數將資料映射到高維空間，使其線性可分：

  • RBF Kernel（高斯核）：最常用，$K(x,z)=\exp(-\gamma||x-z||^2)$
  • Polynomial Kernel：$K(x,z)=(x \cdot z + c)^d$
  • Linear Kernel：適合高維稀疏資料

英文技術定義

A Support Vector Machine (SVM) is a discriminative classifier that finds the optimal separating hyperplane by maximizing the margin between classes. Support vectors are the training examples lying on the margin boundary; they alone determine the decision boundary. The kernel trick implicitly maps data into a high-dimensional feature space, enabling SVM to solve non-linearly separable problems efficiently without computing the explicit mapping.

Soft Margin SVM

處理不可完全分開的資料
  • 允許少量分類錯誤（Slack Variables ξᵢ）
  • 超參數 C：控制錯誤容忍度
  • C 大 → 嚴格邊界，易過擬合
  • C 小 → 寬鬆邊界，易欠擬合

重要術語

  • Hyperplane：超平面（決策邊界）
  • Margin：邊界（越大越好）
  • Support Vectors：支援向量
  • Kernel Function：核函數

決策樹（Decision Tree）
Decision Tree

核心概念

決策樹以樹狀結構進行分類或回歸，每個內部節點（Internal Node）代表一個特徵的測試條件，每個葉節點（Leaf Node）代表預測結果。

節點分裂標準

熵（Entropy）：$H(S) = -\sum_{c} p_c \log_2 p_c$

資訊增益（Information Gain）：
$IG(S, A) = H(S) - \sum_{v \in vals(A)} \frac{|S_v|}{|S|} H(S_v)$

Gini Impurity（CART 使用）：
$Gini(S) = 1 - \sum_c p_c^2$
選擇資訊增益最大（或 Gini 最小）的特徵作為分裂點。

主要演算法比較

演算法分裂標準特點
ID3Information Gain只支援類別特徵
C4.5Gain Ratio支援連續特徵、缺失值
CARTGini / MSE二元分裂、支援回歸

過擬合與剪枝

剪枝（Pruning）
  • 預剪枝（Pre-pruning）：設最大深度、最小樣本數
  • 後剪枝（Post-pruning）：先建完整樹再修剪

集成方法延伸

  • Random Forest：多棵決策樹的 Bagging
  • Gradient Boosting：序列式 Boosting（XGBoost）
來源：通識（Decision Tree）| wiki/concepts/ml-fundamentals/decision-tree.md

回歸分析（Regression）
Regression Analysis

線性回歸（Linear Regression）

預測值：$\hat{y} = w_0 + w_1 x_1 + w_2 x_2 + ... + w_n x_n$

損失函數（MSE）：$L = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$

梯度下降更新：$w \leftarrow w - \alpha \frac{\partial L}{\partial w}$

邏輯斯回歸（Logistic Regression）

用於二元分類，以 Sigmoid 函數將線性輸出映射至 [0,1]：

$\sigma(z) = \frac{1}{1 + e^{-z}}$
預測機率：$P(y=1|x) = \sigma(w \cdot x + b)$
損失：Cross-Entropy Loss
注意：Logistic Regression 雖名為「回歸」，但是分類演算法。

正規化（Regularization）

L2 正規化（Ridge Regression）

損失 += λ||w||²，使權重接近 0 但不為 0。防止過擬合，穩定性高。

L1 正規化（Lasso Regression）

損失 += λ|w|，使部分權重精確等於 0。自動特徵選取（稀疏解）。

Elastic Net

結合 L1 + L2，同時兼顧穩定性與稀疏性。

英文術語

  • Gradient Descent：梯度下降
  • Learning Rate (α)：學習率
  • Regularization (λ)：正規化強度
  • Sigmoid / Activation Function：激活函數
來源：通識（Regression）| wiki/concepts/ml-fundamentals/regression.md

分群演算法（Clustering）
Clustering Algorithms

K-Means 演算法

最常見的非監督式學習演算法，將 n 個資料點分成 K 個群集。

演算法步驟
  1. 隨機初始化 K 個中心點（Centroid）
  2. 將每個資料點分配至最近的中心點
  3. 重新計算每個群集的中心點（取平均）
  4. 重複步驟 2-3 直到收斂
目標：最小化群內距離平方和（WCSS）
$J = \sum_{k=1}^{K} \sum_{x \in C_k} ||x - \mu_k||^2$
注意：K-Means 對初始點敏感（建議使用 K-Means++ 初始化）、對離群值敏感、需要預先指定 K。

選擇最佳 K 值

Elbow Method（手肘法）

繪製 K 值 vs WCSS 圖，選擇「手肘點」（WCSS 下降明顯趨緩的 K）。

Silhouette Score

衡量每個樣本與同群的凝聚度 vs 與其他群的分離度，分數越高越好（範圍 -1 到 1）。

其他分群方法

方法特點
Hierarchical Clustering產生樹狀圖（Dendrogram），無需預設 K
DBSCAN密度導向，可發現任意形狀群集、自動辨識離群值
GMM高斯混合模型，軟分配（Soft Assignment）

Ch.3 深度學習基礎
神經網路與感知器
Neural Networks & Perceptron

感知器（Perceptron）

神經網路的最小單元，模擬生物神經元。接收多個輸入，計算加權總和，通過激活函數輸出。

$z = \sum_{i=1}^{n} w_i x_i + b$
$a = f(z)$   （激活函數）

常用激活函數

函數公式特點
Sigmoid1/(1+e⁻ˢ)輸出 [0,1]，二分類
Tanh(eˢ-e⁻ˢ)/(eˢ+e⁻ˢ)輸出 [-1,1]
ReLUmax(0, z)最常用，解決梯度消失
Softmaxeᶻⁱ/Σeᶻʲ多分類輸出層

反向傳播（Backpropagation）

訓練流程
  1. 前向傳播（Forward Pass）：計算預測輸出
  2. 計算損失（Loss）：比較預測與真實值
  3. 反向傳播（Backward Pass）：用鏈式法則計算各層梯度
  4. 更新參數（Weight Update）：梯度下降
梯度消失（Vanishing Gradient）：深層網路中，梯度在反向傳播時指數衰減，使淺層權重無法有效更新。ReLU 和 Batch Normalization 可緩解此問題。

英文核心術語

  • Weight / Bias：權重 / 偏置
  • Gradient Descent：梯度下降
  • Chain Rule：鏈式法則
  • Epoch / Batch / Mini-batch：訓練週期 / 批次

卷積神經網路（CNN）
Convolutional Neural Network (CNN)

核心元件

卷積層（Convolutional Layer）

使用卷積核（Filter/Kernel）在輸入特徵圖上滑動，提取局部特徵。多個不同的卷積核可提取不同特徵（邊緣、紋理等）。

池化層（Pooling Layer）

Max Pooling：取區域最大值，降低特徵圖尺寸，提高平移不變性。

全連接層（Fully Connected Layer）

卷積層提取的特徵圖展平後，透過全連接層進行最終分類。

CNN 優勢：參數共享（Parameter Sharing）大幅減少參數量；局部感受野（Receptive Field）捕捉空間局部特徵。

英文技術定義

A Convolutional Neural Network (CNN) is a deep learning architecture designed for processing grid-structured data such as images. CNNs exploit three key ideas: local connectivity (each neuron connects to a local region of the input), parameter sharing (the same filter is applied across all spatial positions), and hierarchical feature extraction (early layers detect edges; deeper layers detect complex patterns). These properties make CNNs highly effective for image classification, object detection, and segmentation tasks.

重要超參數

參數說明
Filter Size卷積核大小（如 3×3, 5×5）
Stride卷積核滑動步長
Padding邊緣補零，保持特徵圖尺寸
Depth卷積核數量（輸出通道數）

經典架構

  • LeNet-5（1998）：最早 CNN 應用於手寫數字辨識
  • AlexNet（2012）：深度學習影像競賽突破
  • ResNet（2015）：殘差連接解決梯度消失

循環神經網路與 LSTM
RNN & Long Short-Term Memory (LSTM)

循環神經網路（RNN）

RNN 設計用於處理序列資料（文字、語音、時間序列）。每個時間步的隱藏狀態 $h_t$ 由當前輸入 $x_t$ 和前一時間步的隱藏狀態 $h_{t-1}$ 共同決定：

$h_t = \tanh(W_h h_{t-1} + W_x x_t + b)$
RNN 的問題：梯度消失 / 梯度爆炸。長序列中，早期資訊難以傳遞至後期，導致「長期依賴問題（Long-term Dependency Problem）」。

Gradient Clipping

限制梯度最大值，防止梯度爆炸：$g \leftarrow g \cdot \min(1, \theta/||g||)$

長短期記憶網路（LSTM）

LSTM 透過閘控機制（Gating Mechanism）選擇性地記憶或遺忘資訊，解決長期依賴問題。

三個閘（Gate）的功能
  • Forget Gate（遺忘閘）：決定丟棄 Cell State 中哪些資訊
  • Input Gate（輸入閘）：決定哪些新資訊寫入 Cell State
  • Output Gate（輸出閘）：決定輸出哪部分 Cell State
LSTM vs Transformer：LSTM 本質上是序列化處理，無法平行計算。Transformer 透過 Self-Attention 實現平行化，訓練效率遠高於 LSTM，已成為 NLP 主流架構。（來源：[[source-vaswani-2017-attention]]）

Deep Learning Training Techniques

防止過擬合

Dropout

Ch.4 Transformer 架構
Transformer：Attention Is All You Need
Transformer Architecture (Vaswani et al., 2017)

核心貢獻

Vaswani et al.（2017）提出 Transformer，完全捨棄 RNN 與 CNN，僅使用 Attention 機制建立序列模型，實現完全平行化訓練。

Encoder-Decoder 架構：
Encoder：N=6 層，每層包含 Multi-Head Self-Attention + Feed-Forward
Decoder：N=6 層，額外加入 Cross-Attention（關注 Encoder 輸出）

Scaled Dot-Product Attention

$\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right)V$
為何除以 $\sqrt{d_k}$？當 $d_k$ 很大時，點積值方差增大，使 Softmax 進入梯度極小的區域（梯度消失）。除以 $\sqrt{d_k}$ 使方差縮放回 1。（來源：[[source-vaswani-2017-attention]]）

Multi-Head Attention

$\text{MultiHead}(Q,K,V) = \text{Concat}(h_1,...,h_H)W^O$
where $h_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$
  • 使用 h=8 個並行 Attention Heads
  • 每個 Head：$d_k = d_v = d_{model}/h = 64$
  • 不同 Head 學習不同子空間的依賴關係

Positional Encoding

Transformer 無 RNN 的序列性，需加入位置資訊：

$PE_{(pos,2i)} = \sin(pos / 10000^{2i/d_{model}})$
$PE_{(pos,2i+1)} = \cos(pos / 10000^{2i/d_{model}})$
The Transformer replaces recurrence with self-attention, allowing all positions in a sequence to interact simultaneously. This enables parallelization unavailable in RNNs, dramatically reducing training time while achieving state-of-the-art results. (Source: Vaswani et al., 2017, NIPS)
來源：[[source-vaswani-2017-attention]] | wiki/concepts/deep-learning/transformer-architecture.md

Self-Attention 機制詳解
Self-Attention Mechanism in Depth

Query、Key、Value 的概念

資訊檢索的類比
  • Query (Q)：你在問什麼？（查詢向量）
  • Key (K)：每個位置的「標籤」（鍵向量）
  • Value (V)：每個位置的實際內容（值向量）

透過 Q 與 K 計算相似度（Attention Score），決定從 V 中汲取多少資訊。

計算步驟

  1. 線性投影：Q = XW^Q, K = XW^K, V = XW^V
  2. 計算 Attention Score：$S = QK^T / \sqrt{d_k}$
  3. Softmax 正規化得到 Attention Weights
  4. 加權求和 V：Output = Attention Weights × V

與 Cross-Attention 的區別

Self-AttentionCross-Attention
Q 來源輸入序列本身Decoder 當前層
K, V 來源輸入序列本身Encoder 輸出
用途序列內部依賴序列間對齊
使用位置Encoder & Decoder僅 Decoder

Masked Self-Attention（Decoder 中）

Decoder 的 Self-Attention 採用因果遮罩（Causal Mask）：在計算 Attention Score 後，對「未來位置」設為 $-\infty$，使 Softmax 後這些位置的權重為 0。保證生成第 i 個詞時，只能關注位置 1 到 i-1。（來源：[[source-vaswani-2017-attention]]）

英文術語

  • Attention Weight：注意力權重
  • Causal Mask：因果遮罩
  • Context Vector：上下文向量

位置編碼（Positional Encoding）
Positional Encoding

為何需要位置編碼？

Transformer 的 Self-Attention 是排列不變（Permutation-Invariant）的：無論輸入序列的順序如何排列，注意力機制的輸出相同。因此必須人為注入位置資訊。

比較 RNN 與 Transformer 對位置資訊的處理方式：RNN 天然包含位置資訊（輸入順序決定 hidden state 更新順序）；Transformer 需要明確的 Positional Encoding。

Sinusoidal Positional Encoding

$PE_{(pos,2i)} = \sin\!\left(\frac{pos}{10000^{2i/d_{model}}}\right)$

$PE_{(pos,2i+1)} = \cos\!\left(\frac{pos}{10000^{2i/d_{model}}}\right)$

pos 是序列中的位置，i 是維度索引。每個維度對應不同頻率的正弦波。

Sinusoidal vs Learned Embedding

特性SinusoidalLearned Embedding
訓練參數無（固定函數）有（可學習）
可外推長度可外推（見過更長序列）僅限訓練時的長度
效果與 Learned 幾乎相同與 Sinusoidal 幾乎相同
原始論文選擇 Sinusoidal 的原因：可能允許模型外推至訓練時未見過的更長序列長度。（來源：[[source-vaswani-2017-attention]]）

現代改進

RoPE（Rotary Position Embedding）

LLaMA、GPT-NeoX 等現代 LLM 使用旋轉位置編碼，在 Attention 計算中直接編碼相對位置，外推能力更強。

強化學習基礎概念
Reinforcement Learning Fundamentals

核心元素（MDP 五元組）

MDP = (S, A, P, R, γ)
S：狀態空間（State Space）
A：動作空間（Action Space）
P：狀態轉移機率（Transition Probability）
R：獎勵函數（Reward Function）
γ：折扣因子（Discount Factor, 0 < γ ≤ 1）
直覺理解：代理人（Agent）在環境（Environment）中執行動作（Action），收到獎勵（Reward）並轉移至新狀態（State），目標是最大化長期累積獎勵。

折扣累積獎勵（Discounted Return）

$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + ... = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$

價值函數

狀態價值函數 V(s)

在狀態 s 下，遵循策略 π 的期望累積獎勵：
$V^\pi(s) = \mathbb{E}_\pi[G_t | S_t = s]$

動作價值函數 Q(s,a)

在狀態 s 執行動作 a 後，遵循策略 π 的期望累積獎勵：
$Q^\pi(s,a) = \mathbb{E}_\pi[G_t | S_t=s, A_t=a]$

Bellman 方程式

$V^\pi(s) = \sum_a \pi(a|s) \sum_{s'} P(s'|s,a)[R(s,a,s') + \gamma V^\pi(s')]$
In Reinforcement Learning, an agent interacts with an environment modeled as a Markov Decision Process (MDP). The agent observes states, takes actions, and receives rewards. The goal is to find an optimal policy π* that maximizes the expected discounted cumulative reward.

Q-Learning 演算法
Q-Learning Algorithm

Q-Learning 概述

Q-Learning 是一種無模型（Model-free）、離策略（Off-policy）的強化學習演算法，直接學習最優動作價值函數 Q*(s,a)，無需知道環境的轉移機率。

Q 值更新規則

$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]$

其中：
α：學習率（Learning Rate）
γ：折扣因子（Discount Factor）
$r + \gamma \max_{a'} Q(s', a')$：TD Target（時差目標）
$[\cdot]$：TD Error（時差誤差）
Q-Table：對於小型離散狀態空間，Q(s,a) 以查表（Q-Table）儲存。狀態-動作空間大時，改用神經網路近似（DQN）。

Exploration vs Exploitation

ε-greedy 策略
  • 以機率 ε 隨機探索（Exploration）
  • 以機率 1-ε 選擇已知最優動作（Exploitation）
  • 通常 ε 從高值逐漸衰減

Q-Learning 演算法流程

  1. 初始化 Q-Table（全為 0 或隨機）
  2. 觀察當前狀態 s
  3. 以 ε-greedy 選擇動作 a
  4. 執行動作，觀察 r 和下一狀態 s'
  5. 更新 Q(s, a)
  6. 設 s = s'，回到步驟 3

英文術語

  • Temporal Difference (TD)：時間差分學習
  • Greedy Policy：貪婪策略（選 Q 最大的動作）
  • Convergence：在 α 滿足條件時 Q-Learning 保證收斂
來源：通識（Q-Learning）| wiki/concepts/reinforcement-learning/

深度 Q 網路（DQN）
Deep Q-Network (DQN) — Mnih et al., 2013

動機：擴展 Q-Learning 到高維空間

傳統 Q-Learning 需要 Q-Table，無法處理高維連續狀態空間（如 Atari 遊戲的像素輸入）。DQN 使用神經網路（CNN）近似 Q 函數：

$Q(s, a; \theta) \approx Q^*(s, a)$

兩大核心技術

1. Experience Replay（經驗回放）
  • 將每次互動的 (s, a, r, s') 存入 Replay Buffer
  • 訓練時從 Buffer 隨機取樣 mini-batch
  • 目的 1：打破資料的時間相關性（IID 假設）
  • 目的 2：提高資料使用效率
2. Target Network（目標網路）
  • 建立一份 Q-Network 的副本（Target Network）
  • TD Target 使用 Target Network 計算，每隔 C 步更新
  • 目的：穩定訓練目標，防止「追逐移動靶」的不穩定問題

DQN 損失函數

$L(\theta) = \mathbb{E}_{(s,a,r,s') \sim \mathcal{D}}\!\left[\left(r + \gamma \max_{a'} Q(s', a'; \theta^-) - Q(s, a; \theta)\right)^2\right]$

θ：Q-Network 參數
θ⁻：Target Network 參數（固定不更新）

英文技術定義

Deep Q-Network (DQN) extends Q-Learning by approximating the Q-function with a deep neural network. Two key innovations stabilize training: (1) Experience Replay stores transitions in a replay buffer and samples random mini-batches, breaking temporal correlations in training data; (2) the Target Network provides a temporally stable learning target by periodically copying the Q-network weights, preventing the "moving target" problem inherent in vanilla Q-Learning. (Mnih et al., 2013)

DQN 成就

DQN 在 49 款 Atari 遊戲中，以像素輸入達到人類水準或更高的效能。（來源：Mnih et al., 2013，arXiv:1312.5602）

大型語言模型基礎概念
Large Language Models: Fundamentals

什麼是 LLM？

大型語言模型（Large Language Model，LLM）是以 Transformer Decoder 為基礎，在數兆個 Token 的文字資料上預訓練的語言模型。核心任務是預測下一個 Token（自迴歸生成）。

「進階詞語接龍」：LLM 在推論時，接收 Prompt，不斷預測並輸出下一個 Token，直到生成終止符（EOS）。

Token 與 Tokenization

Token 的基本單位
  • Token 不等於一個字，可能是字根、子詞（Subword）
  • 常用 BPE（Byte Pair Encoding）進行切分
  • 「Tokenization」是 AI 與人類之間的語言橋接
  • GPT-3 的 Context Window：4096 tokens

Embedding（嵌入向量）

將 Token 映射至高維連續向量空間（$d_{model}$ 維），語義相近的 Token 在向量空間中距離較近。

英文技術定義

A Large Language Model (LLM) is a Transformer-based neural network pretrained on massive text corpora using a self-supervised objective — predicting the next token given prior context (causal language modeling). At inference, the model autoregressively generates tokens one at a time, sampling from the predicted probability distribution over its vocabulary. Modern LLMs exhibit emergent capabilities such as in-context learning, chain-of-thought reasoning, and instruction following.

LLM 訓練三階段

1. 預訓練（Pre-training）

在大規模無標記文字上，以預測下一個 Token 為目標的自監督學習。

2. 監督微調（SFT）

在人類撰寫的指令-回答對上微調，使模型學會遵循指令（Instruction Following）。

3. RLHF 對齊

使用 PPO 演算法根據人類偏好的獎勵模型，進一步優化模型輸出的有益性、無害性與誠實性。

情境學習（In-Context Learning, ICL）

無需更新模型參數的「學習」
  • Zero-shot：只提供任務描述，不提供範例
  • One-shot：提供 1 個範例
  • Few-shot：提供少量範例（通常 < 10 個）
In-context learning (ICL) refers to the ability of large language models to perform new tasks from examples provided in the prompt, without any gradient-based parameter updates. Brown et al. (2020) demonstrated that GPT-3 (175B parameters) achieves competitive performance on many NLP benchmarks using few-shot prompting alone, challenging the need for task-specific fine-tuning.

Prompt Engineering

Chain-of-Thought（思維鏈）提示

在 Prompt 中加入逐步推理過程的範例，誘導模型展示中間推理步驟，大幅提升複雜推理任務的表現。

RAG（檢索增強生成）

LLM 的知識截止於訓練資料日期。RAG 通過在推論時動態檢索外部知識，解決知識更新和特定領域問題。

RAG 工作流程
  1. 使用者提問（Query）
  2. 將 Query 轉為 Embedding 向量
  3. 在向量資料庫中檢索最相關的文件（Retrieval）
  4. 將檢索結果與 Query 合併為 Prompt
  5. LLM 根據 Prompt 生成最終答案（Generation）
RAG vs Fine-tuning：RAG 適合需要即時更新知識的場景（如問答系統）；Fine-tuning 適合改變模型行為風格或特定領域技能。

AI Agent

Agent 的核心概念

AI Agent 是能夠感知環境、決策、執行動作，並透過工具（Tool）與外部世界互動的 LLM 應用架構。

ReAct（Reasoning + Acting）

Agent 交替執行「思考（Reasoning）」與「行動（Acting）」：
Think → Act → Observe → Think → ...

重要術語

  • Vector Database：向量資料庫（儲存 Embedding）
  • Semantic Search：語意搜尋
  • Hallucination：幻覺（LLM 生成不正確但看似合理的內容）
  • Context Window：上下文視窗長度
  • Tool Use / Function Calling：工具呼叫

Ch.8 英文考題解題示範
考題示範：Transformer Self-Attention
Exam Practice: Transformer & Self-Attention

原題（English）

Question: Explain the Self-Attention mechanism in the Transformer model. (1) Write the formula for Scaled Dot-Product Attention. (2) Why do we divide by $\sqrt{d_k}$? (3) What is the advantage of Transformer over RNN in handling long sequences?

中文翻譯

題目翻譯

請解釋 Transformer 模型中的 Self-Attention 機制。(1) 寫出 Scaled Dot-Product Attention 的計算公式。(2) 為什麼要除以 $\sqrt{d_k}$？(3) Transformer 在處理長序列時相較 RNN 有何優勢？

關鍵字

Self-Attention Query / Key / Value Scaled Dot-Product Long-range Dependency

參考答案

(1) 公式：

$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right)V$

(2) 除以 $\sqrt{d_k}$ 的原因：

  • 當 $d_k$ 大時，Q 與 K 的點積值方差增大（方差為 $d_k$）
  • Softmax 在絕對值大的輸入下梯度極小（饋和），導致梯度消失
  • 除以 $\sqrt{d_k}$ 使點積方差縮回 1，保持梯度穩定

(3) Transformer vs RNN 長序列優勢：

  • RNN 需 O(n) 步才能連接序列兩端，長距離依賴困難
  • Self-Attention 任意兩位置直接計算（O(1) 路徑長度）
  • Transformer 可完全平行化，訓練速度遠快於 RNN
（來源：[[source-vaswani-2017-attention]]）

Ch.8 英文考題解題示範
考題示範：DQN 核心技術
Exam Practice: Deep Q-Network (DQN)

原題（English）

Question: In the Deep Q-Network (DQN) algorithm, two key techniques are introduced to stabilize training. (1) Explain the purpose of Experience Replay. (2) Explain the purpose of the Target Network. (3) Write the DQN loss function.

中文翻譯

題目翻譯

在 DQN 演算法中，引入了兩項關鍵技術來穩定訓練。(1) 解釋 Experience Replay（經驗回放）的用途。(2) 解釋 Target Network（目標網路）的用途。(3) 寫出 DQN 的損失函數。

關鍵字

DQN Experience Replay Target Network TD Error

參考答案

(1) Experience Replay（經驗回放）：

  • 將互動紀錄 (s, a, r, s') 存入 Replay Buffer
  • 訓練時隨機取樣，打破時間相關性，使資料近似 IID 分布
  • 同一筆資料可被多次使用，提高樣本效率

(2) Target Network（目標網路）：

  • TD Target 以固定的 Target Network $\theta^-$ 計算，每隔 C 步更新
  • 防止 Q-Network 追逐不斷移動的目標，穩定訓練過程

(3) DQN 損失函數：

$L(\theta) = \mathbb{E}\!\left[\left(r + \gamma \max_{a'} Q(s',a';\theta^-) - Q(s,a;\theta)\right)^2\right]$
（來源：Mnih et al., 2013，arXiv:1312.5602）

考題示範：傳統機器學習
Exam Practice: Traditional ML (SVM & KNN)

考題一：SVM Kernel

Q: What is the "kernel trick" in SVM? Why is it useful for non-linearly separable data?
中文翻譯與解答

什麼是 SVM 的「核技巧」？對線性不可分資料有何用途？

答：核技巧（Kernel Trick）使用核函數 $K(x_i, x_j) = \phi(x_i)^\top \phi(x_j)$ 計算高維空間的內積，而無需明確計算映射 $\phi(\cdot)$。當資料在原始空間線性不可分時，核函數隱式地將資料映射到高維（甚至無限維）特徵空間，使其線性可分。

常用核函數：RBF Kernel $K(x,z)=\exp(-\gamma||x-z||^2)$

考題二：KNN 超參數

Q: In KNN, what happens when K=1 and K=N (N = total training samples)? How do you choose an appropriate K?
中文翻譯與解答

KNN 中 K=1 和 K=N 時各會發生什麼？如何選擇適當的 K？

K=1：完全以最近鄰的標籤決定，決策邊界過於不規則，訓練集準確率 100%，但嚴重過擬合（高變異數）。

K=N：以所有訓練樣本的多數決，始終預測最常見類別，嚴重欠擬合（高偏差）。

選擇方法：以交叉驗證（Cross-Validation）遍歷不同 K 值，選取驗證集誤差最小的 K。
